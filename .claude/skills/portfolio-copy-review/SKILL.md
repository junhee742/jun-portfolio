# 포트폴리오 카피 점검

카피 품질을 사람 감각이 아니라 **채점 계약서**로 관리한다. 문구를 고칠 때마다 같은 기준으로 다시 잴 수 있어야 회귀를 막을 수 있다.

이 저장소가 이미 AI 답변 회귀검증에서 쓰는 원리를 카피에 적용한 것이다 — 고친 것보다 **깨뜨리지 않은 것**을 확인한다.

## 구성

| 파일 | 역할 |
|---|---|
| `RUBRIC.md` | 5차원 0.0~5.0 점수 밴드. 채점 계약서. |
| `banned_phrases.json` | 기술 포트폴리오 전용 금지 패턴 + 추상명사 임계 + 도메인 예외어 |
| `scripts/check.py` | 결정론적 검사기. LLM 없이 동작. |
| `docs/provenance.md` | 근거 대장. 저장소 루트의 `docs/` 에 있다. |

## 실행

```bash
python3 .claude/skills/portfolio-copy-review/scripts/check.py
python3 .claude/skills/portfolio-copy-review/scripts/check.py --json   # 기계 판독용
```

`high` 심각도 적발이나 경계 위반이 있으면 **종료 코드 1**을 낸다. 배포 전 게이트로 쓸 수 있다.

## 작업 순서

1. **수치를 추가·변경했다면 `docs/provenance.md` 를 먼저 갱신한다.** 출처와 확인 환경을 못 채우는 수치는 공개하지 않는다.
2. 카피를 고친다.
3. `check.py` 를 돌린다.
4. `high` 적발과 경계 위반은 **전부 고친다.** 예외 없다.
5. `medium` 은 판단 항목이다. 아래 "오탐 다루기"를 읽고 결정한다.
6. `RUBRIC.md` 의 `[judge]` 항목은 사람이 채점해 점수표를 갱신한다.
7. `npm run check && npm run build` 로 마무리한다.

## 오탐 다루기 — 중요

**점수를 올리려고 좋은 문장을 망치지 마라.** 이 검사기는 휴리스틱이고, 실제로 오탐을 낸 적이 있다.

- `범위`, `조건`, `기준` 은 이 저장소에서 대부분 **의미를 지는 도메인 용어**다. `확인한 범위`는 이 포트폴리오의 정직성 장치라 줄이면 안 된다. 그래서 `abstract_noun_exempt` 목록으로 밀도 계산에서 제외한다.
- `~할 수 있습니다` 는 약한 마무리일 때만 문제다. `그 파일만 재실행할 수 있습니다` 처럼 실제 기능을 서술하면 정상이다.

패턴이 반복적으로 오탐이면 **카피가 아니라 `banned_phrases.json` 을 고친다.** 예외어를 추가하거나 패턴을 좁힌다. 그 판단을 `note` 에 남긴다.

## 절대 규칙

`AGENTS.md` 의 내용 규칙이 이 스킬보다 우선한다.

- 근거 대장에 없는 수치를 공개하지 않는다.
- 각 케이스 스터디 마지막의 경계 진술 절을 지우거나 축약하지 않는다.
- 확인 환경을 넘어서는 표현을 쓰지 않는다. 한 서비스 결과를 전체로, 내부 검증을 운영 성과로 넓히지 않는다.
- 고객사명·내부 URL·저장소명·노션 페이지 ID는 사이트에도 `docs/` 에도 쓰지 않는다. **이 저장소는 GitHub 공개다.**

## 기준선

2026-08-06 실측 **24.0 / 25.0**.

| 차원 | 점수 |
|---|---|
| 구체성 | 5.0 |
| 근거 정합성 | 5.0 |
| 표현 | 5.0 |
| 스캔 가능성 | 5.0 |
| 구조 다양성 | 4.0 |

구조 다양성만 4.0이다. 5개 케이스가 모두 4절이라 걸리는데, 쪼갤 이유가 있는 케이스가 없어 **의도적으로 유지한다.** 자세한 근거는 `RUBRIC.md` 3번 항목에 있다.

점수가 이 기준선 아래로 내려가면 원인을 찾아 고친 뒤 배포한다.

## 설계 출처

공개 커리어 스킬 4종(`Paramchoudhary/ResumeSkills`, `modu-ai/cowork-plugins` 의 moai-career, `ARPeeketi/claude-resume-kit`, `daypunk/LockedIn`)을 원문 대조해 이 저장소에 맞게 재구성했다.

- 다단 채점 루브릭과 산출물별 금지어 사전 → LockedIn
- 근거 추적과 날조 금지 게이트 → claude-resume-kit 의 Provenance Flags
- 검색되는 포트폴리오, 최근 경력 비중 → moai-career

일반 자소서 금지어 사전은 이 장르에 걸리지 않는다. LockedIn 의 한국어 금지어 전체를 이 저장소 카피에 교차 검사했을 때 적발이 0건이었다. 기술 포트폴리오의 AI 문체는 어휘가 아니라 **구조의 균일함**에서 드러나기 때문에, 헤딩 중복·문두 반복·문말 편중·템플릿 절 구성을 대신 잡는다.
