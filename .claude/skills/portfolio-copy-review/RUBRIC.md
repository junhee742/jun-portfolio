자동 항목은 **[auto]**, 판단이 필요한 항목은 **[judge]** 로 표시한다.

기준선: 2026-08-06 실측. 총점 **21.0 / 25.0**.

## 총점 해석

| 총점 | 판정 |
|---|---|
| 23.0 이상 | 배포 가능 |
| 20.0 ~ 22.9 | 배포 가능하나 다음 라운드 개선 항목을 남긴다 |
| 17.0 ~ 19.9 | 배포 전 수정 |
| 16.9 이하 | 구조부터 다시 |

**2026-08-06 기준 21.0 / 25.0 — 배포 가능, 개선 여지 있음.**

낮은 순: 표현 3.5 → 구조 다양성 4.0 = 스캔 가능성 4.0 → 구체성 4.5 → 근거 정합성 5.0

## 채점 후 할 일

1. `scripts/check.py` 를 돌려 auto 항목을 갱신한다.
2. 점수가 내려간 차원이 있으면 그 차원의 밴드 설명을 근거로 수정한다.
3. 수치를 새로 추가했으면 `docs/provenance.md` 를 먼저 갱신한다. **대장 없는 수치는 공개하지 않는다.**
